# Screenshot gallery

These are captures of running Kog frontends, not UI mockups.

- `qt-desktop.png`: Qt on Linux, browsing and playing a Chrono Trigger SPC album.
- `terminal.png`: the Unix terminal frontend in xterm, with the same album queued.
- `web-desktop.jpg`: the embedded web frontend at its desktop breakpoint.
- `web-mobile.jpg`: the same web frontend at a 390 × 844 phone viewport.
- `android.png`: the native Android app in an emulator, browsing a server album.

Qt, terminal, and web images were captured on September 26, 2026 from the local
build of `e31b194`; the Android capture is from September 25. Later changes
through `e3b6019` do not change the pictured layouts. Desktop/web captures use
an isolated demo library and settings, with playback muted. Qt's normal column
visibility and width controls were used to fit the useful columns in view.

The gallery includes app interfaces and album art; music files are not included.
Album artwork remains the property of its respective rights holders.
